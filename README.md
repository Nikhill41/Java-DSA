## 🚀 Getting Started

### 📋 Prerequisites
- ☕ **Java Development Kit (JDK)** 8 or higher
- 💻 **Java IDE** (IntelliJ IDEA, Eclipse, VS Code + Java extensions)
- 📖 Basic understanding of Java syntax
- ✏️ Text editor or IDE for code editing

### ⚡ Quick Installation

**1️⃣ Clone the repository:**
```bash
git clone <repository-url>
cd "DSA with java(Kunal Kushwaha)"
```

**2️⃣ Navigate to a specific topic:**
```bash
cd "05-Linear Search"
# or any other folder
```

**3️⃣ Compile Java file:**
```bash
javac FileName.java
```

**4️⃣ Run the program:**
```bash
java FileName
```

## 📖 How to Use

### 🎓 For Learning

1. ✅ **Start with basics**: Begin with 01-Lectures and progress numerically
2. 📖 **Understand concepts**: Read through code and comments
3. ▶️ **Run programs**: Compile and execute to see output
4. 🧪 **Experiment**: Modify code and test variations
5. ✍️ **Take notes**: Understand the "why" behind algorithms

### 🏋️ For Practice

1. 🤔 **Solve before looking**: Try problems without reading solutions
2. 🎯 **Refer to examples**: Check solutions when stuck
3. 💪 **Rough folder**: Extra practice and LeetCode problems
4. 📊 **Optimize**: Work on improving time/space complexity
5. 📝 **Document**: Keep notes of learning points

### 💡 Tips for Success

- **Break problems down**: Divide complex problems into smaller parts
- **Test edge cases**: Always test with boundary values
- **Time complexity**: Understand O(n), O(n²), O(log n) etc.
- **Space complexity**: Be mindful of extra memory usage
- **Consistency**: Code daily, even for 30 minutes
- **Debug**: Use print statements or IDE debugger
